# Chandhru R — Portfolio

Personal portfolio built with Astro, React, and Tailwind CSS. It highlights my projects, coding activity, bookshelf, and contact information.

## Local development

Requirements: Node.js 20 or newer and pnpm 9 or newer.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Build the static site with:

```sh
pnpm build
```

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy-pages.yml` builds and deploys the site to GitHub Pages whenever changes are pushed to `main`.
